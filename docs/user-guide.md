# 使用指南

首次使用先看[安装与初始化](install.md)。外观在帮助中切换系统/浅/深色；版本和本轮剩余事项见[逐项跟踪](completion-tracker.md)。

最新行为：快照缺失选择恢复、未保存上下文保护、密钥读取期限、Compose版本/保存状态/等待边界、睡眠证据失效及后端历史分页，见[RI01–RI18交付](improvement-status.md)。旧构建/调查记录仍按其当时状态保留。

[返回 README](../README.md) · [完整功能](features.md) · [故障排查](troubleshooting.md)

以下流程描述当前入口；尚未完成的真实环境验收见 [人工验收清单](validation.md)。建议从自己控制的测试请求或合成 HAR 开始。

## 本机 HTTP(S) 抓包

1. 打开「抓包」，确认当前项目和批次，再点击「开始抓包」。默认代理端口为 `8080`；修改端口前先停止采集。
2. 在「设置 → 抓包与代理」的本机代理入口启用系统代理，按 macOS 提示授权。代理监听和系统代理开关是两件事；只开启监听不会让全部应用自动走代理。
3. HTTP 请求可直接查看。HTTPS 需要先安装并信任当前项目生成的 CA；从「连接手机」或证书信息入口找到证书，Mac 端可用「钥匙串访问」导入并设置所需信任。
4. 向自己的测试环境发起请求，默认在Host下每个请求独立一行；切换“目录折叠”才按目录/方法/路径展开。每次请求仍有独立ID。
5. 结束后停止采集并恢复系统代理。应用正常退出会尝试恢复先前代理，但强退、崩溃和网络服务切换仍需人工核对。

新项目默认不解密 HTTPS；可先体验 HTTP，再在工具栏/手机连接入口主动启用全部解密或按 Host 单独启用。已有项目保留保存的策略。修改只影响新连接；复用连接可能需要重新建立。仅有 CONNECT 记录不代表已解密或正文为空。

## 手机接入

1. 手机与 Mac 连接同一可信 Wi-Fi，打开「连接手机与诊断」，选择可达网卡/IP，开启局域网 HTTP 代理。此步骤不修改 Mac 系统代理，也不自动打开全部 HTTPS 解密。
2. 点击生成配对二维码并用手机扫码，先记录直达证据；设置手机 Wi-Fi 代理，首次请求后在 Mac 允许该网络地址，再点引导页的 HTTP 验证。需要 HTTPS 时再开启解密并安装 CA。iOS 下载并安装 `.mobileconfig` 描述文件；Android 下载 `.crt` 并在系统设置安装用户 CA。
3. iOS 还需到「设置 → 通用 → 关于本机 → 证书信任设置」启用完全信任。仅安装描述文件不够。
4. 在引导页打开 HTTPS 验证，看到 Mac 上对应的解密证据后，再重新建立目标 App 连接；浏览器成功不能代表目标 App 已成功。
5. 抓包后关闭 Wi-Fi 代理，不再使用时按需要移除 CA 信任。

Android 7+ 的正式 App 可能拒绝用户 CA，证书固定的 App 也可能无法解密；该工具不自动绕过这些限制。切换独立项目后 CA 也隔离，设备上原有信任不一定适用于新项目。

## 查看、筛选与比较

- 按设备、环境、时间、方法、Host、状态、业务状态或 Trace 筛选；区分匹配数、已加载数与批次总量。
- 结构树支持逐层展开、收起、方向键与 Home/End；时序与实例列表按需加载。可以命名保存当前筛选。
- 请求详情分为概要、请求、响应、耗时、规则影响与关联。正文预览不是完整存档；继续读取只补本地已保存部分。
- JSON 使用 Pointer 定位，例如 `/data/items/0/id`；`~0` 表示 `~`，`~1` 表示 `/`，空 Pointer 表示根，`/` 表示空键。
- 对比用于查 Header、Query 与字段变化；配置忽略动态字段后，仍需核对是否掩盖业务差异。
- 聚合和关系计算有规模预算；出现 coverage/partial 时不能把未扫描样本当作通过。

## 发起 AI 调查

1. 在设置中配置供应商、模型、协议和 API Key。支持配置 OpenAI Responses、OpenAI Chat Completions 与 Anthropic Messages 类接口；兼容端点的实际能力仍需人工验证。
2. 选当前筛选、多选请求或 QA 场景作为范围，发起只读分析。空选择、空场景、跨批次引用会明确拒绝，不自动扩大为全部数据。
3. 查看工具轨迹、预算、覆盖范围与证据。请求或配置变化导致旧版本不可读时，创建新范围再分析。
4. 点击证据回到原请求和字段；失效/缺失/截断会显示原因。关系候选和模型判断都不是服务端根因证明。
5. 可停止 Run、查看历史或继续调查。继续会利用持久记录，并不承诺逐指令恢复模型现场；已经发送的写操作不会自动重发。
6. 从 Run 生成报告，补齐人工掌握的复现前置、预期和实际；模型无法观察到的信息保持待补。

供应商 Key 保存在本机独立凭据文件；分析上下文会发给所配置供应商。用户输入的自由文本也可能包含隐私，发送前自行检查。真实供应商验收目前保留为 A11，未将本地 FunctionModel 核查视为完成。

## 调试变更

Map Local、Map Remote、Rewrite 和弱网可人工配置；Agent 调试模式也可发起预览。Map Local 的 Agent 入口只能使用你在当前会话主动共享的文件。

变更流程为：预览目标和 before/after → 确认具体动作版本 → 应用 → 通过新请求检查实际命中 → 恢复。配置或共享文件发生变化时重新预览；冲突不会覆盖当前配置。弱网对经过本代理的流量共享带宽/延迟控制，不修改系统网卡、不模拟丢包。

自动执行可跳过原有规则/弱网等工具的后续审批；新增Shell、代理管理、设备授权和批量发送仍逐次人工批准，但仍保留预览和冲突校验。停止 Run 会收束待审批操作；网络未知结果需人工检查历史和目标端状态。

## QA 工作台

先在抓包页选请求，再打开工作台的 QA 页。不同操作使用不同样本和配置，不必为了只读分析开启调试写权限。

| 入口 | 操作方法与结果 |
| --- | --- |
| 编辑重放 | 修改方法、URL/Query、重复 Header；只有勾选替换正文才覆盖正文。预览后「确认发送一次」，结果入库并关联原请求。 |
| 步骤复现 | 添加请求步骤，配置响应 JSON Pointer 提取变量，在后续步骤引用变量；逐步预览和人工触发，前置失败停止。 |
| 基线回归 | 选择成功场景设为基线，按唯一接口、人工步骤或业务键比较新样本；重复/缺失键和未覆盖步骤单列。 |
| 故障矩阵 | 选择空列表、缺字段、业务错误、401/429/500、延迟或中断模板；预览/应用后人工操作目标 App，记录验证，再恢复矩阵组。 |
| 鉴权诊断 | 检查登录/刷新候选、凭据摘要变化与跳转时间线；缺少流量时补采，不自动获取凭据。 |
| 文件与流 | 查看 MIME、文件元数据、摘要和已保存正文。SSE/WebSocket 保存需先开启，仅影响之后的新流/连接。 |
| 人工验证 | 编辑步骤和预期、标记通过/失败/待查、附请求 ID 与备注，保存后可重新打开。 |
| 证据交接 | 选择报告、预览脱敏证据包并导出；导入包只读阅读，不执行其包含的动作。 |
| 操作历史 | 查看重放/调试/工单骨架的目标、版本、结果和未知状态。查看历史不重新发送请求。 |

重放直连目标，不应用本代理规则/弱网，不自动跟随重定向或重试。即便服务端忽略幂等 Header，写请求也可能产生真实业务副作用。变量、保存的预览与本地草稿可能包含原文，按本地敏感数据管理。

## 场景、项目与环境

「开始场景」记录本次业务操作范围，可命名、结束并人工加入/排除请求。业务规则决定业务成功码和错误字段，关联规则指定业务键及来源。

顶栏选择独立项目。切换会停止采集并等待 Agent/后台任务收束；系统代理仍需核对。环境配置记录 App 版本、构建等信息，不应把环境名称当作流量目标地址已被切换的证明。

## 导入、导出与清理

- HAR 导入创建独立批次；原始导出保留敏感原文，限2万条/20 MiB，并附未包含数。
- OpenAPI/Swagger 使用 JSON 导入，只执行声明支持的子集；unsupported/partial 不算通过。OTLP 使用 JSON Span 导入，不直接接收 protobuf。
- 报告可保存 Markdown/JSON；脱敏证据包限200样本/20 MiB，附来源有效性和未包含信息。
- 清批次可保留报告，来源会标为失效；清分析数据与清项目范围不同。两者均不代表删除本地凭据、旧 Keychain 条目、迁移备份、导出文件或已安装 CA。

完整限额见 [功能与支持边界](features.md)，本地备份与恢复见 [架构说明](architecture.md#数据布局与备份)。


## 本地凭据与旧版升级

在「设置 → 供应商」录入 Key 并保存后，后续启动复用本机凭据，不再访问 Keychain。旧版只存于 Keychain 的 Key 需要重新录入一次；应用不会读取、自动迁移或删除旧条目。编辑供应商时，留空保留已存 Key；需要清空时使用明确的清空选项。跨项目复用需主动选择来源账户，保存后是独立副本，不共享业务数据或后续密钥变更。

文件为 `~/Library/Application Support/com.nekoya.ai-proxy/credentials/auth.json`，目录0700、文件0600，明文存储；同账户进程可读取。已存 Key 不回填表单、不进入业务数据库和证据包。完整数据根备份包含它，SQLite迁移备份不包含它。CA 安装与信任仍由系统/设备管理，与模型 Key 存储分开。

连接与合成工具检查分别主动点击，可能收费；普通启动不会自动调用模型。读文件失败、未配置和401鉴权失败分别处理，保存失败保留当前表单。回执超时先重新打开设置核对，避免重复新建账户。

## 连接诊断与收尾

「连接手机与诊断」按四层列出证据：Mac监听就绪、手机直达引导页、HTTP经过代理、HTTPS已实际解密。点生成配对二维码后开启限时轮询，约2分钟自动停止，可手动再检查；配对标识10分钟失效。过期、网络变化或检测到睡眠间隔后旧证据失效，重新生成并验证。

手机首次请求可能收到403：在Mac的地址列表中选择允许一次或记住，再在手机刷新。撤销会关闭该地址现有代理连接。「记住」按当前项目保存IP许可，不证明物理设备身份，也不表示持续在线；同一IP被其它设备使用仍可能匹配，应及时撤销。停止代理、切项目或切网会关闭连接；手机 Wi-Fi 代理要手动关闭。切项目/清项目数据前，Mac系统代理恢复失败会中止操作并提示。

浏览器四层通过后，目标App仍可能受用户CA限制、证书固定、VPN或QUIC影响。界面列出的原因是候选，不会仅凭浏览器成功声称App解密成功。

## 阅读、显示与帮助

顶栏品牌/空白可拖动，双击缩放。拖动面板分隔条改变宽度；方向键微调，Home或双击恢复默认。窄窗可收起会话栏、将详情全宽显示。输入区和长内容各自滚动，低高度窗口的工具栏和弹窗可滚动。

打开「帮助」（⌘/Ctrl + /）调整100%–200%文字大小、舒适/紧凑密度，或按名称搜索功能并直接跳转。虚拟列表行高随设置变化。Agent上滚阅读时暂停跟随，新内容按钮返回底部；证据返回保留会话阅读位置。Markdown支持列表、表格和代码块，不渲染原始HTML或远程图片，链接显示为文本。

发送前核对本次项目/批次/设备/选择或筛选、Provider和模式；所选旧Run快照另行标记。空选择不自动扩大范围。尚未确认Run创建时保留草稿与引用，回执未知先查执行记录；重试沿用提交标识。停止不撤销已生效的业务写入。

## 缓存与费用

供应商缓存策略有自动、显式启用、关闭。自动只向官方端点发送相应扩展；兼容网关默认不发，确认支持后再启用。不支持参数时手动关闭，失败不自动再次调用收费模型。稳定前缀与会话缓存键有助复用，不承诺固定命中率。逐次请求可见输入/输出、缓存读写、首输出和耗时；供应商未报告或SDK无法辨别的零值显示未知。

本地只读工具缓存独立于供应商缓存，限定项目/Run/Scope版本/配置/脱敏视图/参数，最多128项、8MiB序列化体积，单项1MiB，120秒有效；帮助页可查看/清理。该体积不是Python进程内存上限。不缓存写操作、失败和顶层未知结果。上下文预算超限时移出旧完整轮次并留摘要和事件，最新单轮过大则提示新会话；历史证据仍在执行记录中。


## 抓包列表与等待期限（2026-10-24更新）

结构视图按Host组织，每条真实请求只占一行，显示方法、路径（含查询参数）和状态；不再拆出目录或同接口请求组。相同接口的多次调用仍逐条保留，每个Host每页200条、最新在前，使用上下页读取；整个列表共用一个滚动区域。长路径会省略显示，悬停可看完整路径，右侧详情可核对完整URL。

普通请求总时限120秒；SSE按正文数据、WebSocket按连接收发计算120秒空闲期限。超时显示失败原因，重新打开后上次未完成的记录显示中断。底部状态单独占位，历史引用中已删除/更新的来源不再被统计为有效证据。


## 存储检查、超时与等待

「设置 → 存储 → 检查存储健康」主动读取磁盘余量，并用项目/正文目录内独立临时文件验证创建、读写和删除能力；数据库仅做只读访问，不扫描全部完整性、不删库修复。最近成功保存和失败次数仅统计本次项目打开后的采集，检查通过也不会恢复已经丢失的数据。可复制去掉数据路径的诊断元数据。磁盘无响应时前端会超时，同一后端检查完成前拒绝重复提交。

「设置 → 抓包 → 抓包超时与协议」分别配置普通请求总时限和流空闲时限，范围5–3600秒，默认120秒；保存后用于新请求，已有请求保留启动时策略。SSE/大响应按正文活动计空闲，WebSocket按承载连接收发（含心跳）计空闲。HTTP/2超时关闭承载连接可能中断并行请求；停止代理后可以关闭HTTP/2，重新启动协商HTTP/1，但会改变目标App的协议表现。当前内核未提供可靠的在途单HTTP/2流取消。

主窗口底部和弹窗底部的「任务与等待」显示等待超过1.5秒的操作、开始时间、已等待时间、回执时限和近期错误；只在内存保留最多100条/10分钟的元数据。读取失败返回原功能主动重试；写回执未知先看操作历史并核对真实业务。关闭面板不会取消后台，前端超时也不代表后台已经停止；Agent停止和手机诊断停止轮询仍使用原功能入口。

## 比较缓存和耗时

进入「工作台 → 执行记录 → 缓存与耗时比较」，选择同一会话已有的2–10条Run，再点读取比较。此操作不调用Provider。比较包含输入/输出Token、模型缓存读写、首个模型请求的首输出、完成的模型请求耗时合计、整轮耗时和本地工具缓存命中/未命中增量，可展开逐次模型用量并保存元数据。

只有相同模型、协议、端点指纹、样本版本与规则范围的已完成Run才显示主要条件一致；提示、历史长度、审批等待和工具路径仍可能不同，不能据此自动宣称提速。旧Run缺少对比元数据、供应商未报告指标、执行期间清理过本地缓存时保留未知。失败的模型调用不包含在已完成请求合计中；缓存Token不重复加到输入总量，也不使用无来源单价推算费用。

### 等待、预览与键盘操作补充

设置与工作台处理操作时会暂时禁用当前表单，避免连点或提交后改变参数；关闭窗口不代表取消后台操作。QA先读完新请求再允许编辑，读取失败可点“重新读取所选请求”。切换请求/来源版本，或修改调试参数、授权文件、工单目标后，需重新生成预览。弹窗叠加时Esc只关闭最上层，Tab留在当前弹窗；关闭后返回原焦点。

存储健康页分别统计真正的写入失败和队列已满丢弃；这些是快照事件次数，同一请求可能计多次。后台轮询优先淘汰已完成的任务元数据，保留已追踪的等待记录；最多100条，同时已有100条等待时不再追踪新增记录，实际请求仍按原时限收尾。性能比较的所选记录更新或删除后，旧结果不继续作为当前比较，应重新读取。

## 目录、快照与上下文

抓包默认保留Host下每个请求一行，完整Path与查询串不拆成独立请求。需要Charles式目录时切到「目录折叠」：Host→目录→方法/路径→实际实例，单子目录合并；重复实例默认折叠，每层200节点/实例分页。关注地址后当前Host页的其余地址进入「其他Host」分组。方向键/Home/End导航；搜索临时展开至多200节点，清空搜索恢复原折叠；1万可见行/64层上限会提示缩小范围。证据定位会找目标页而不是只查已加载行。

筛选或场景分析只固定已完成/已终止请求，展示排除的进行中数量；手选包含进行中请求时拒绝创建任务，请等待或移除它们。新请求完成不会修改旧快照；配置/样本真的变化或删除时仍拒读旧版本。失败卡片或范围错误可点击「按原条件创建新快照分析」，读取原始问题和引用，确认新增/移出/版本变化样本后才新建模型任务，旧Run保留；原时间条件继续保留，若要扩大时间请重新选择筛选后发送。范围、鉴权、限流、超时和回执未知使用不同恢复说明，未知回执先核对实际Run。

AI顶部展开「上下文」，设置项目级历史估算/消息预算，下次发送生效。「完整发送预览」在本地估算历史、指令、工具定义、下一条输入、范围与引用，不创建Run或请求模型。UTF-8字节启发式不是精确Tokenizer，供应商包装开销未知；模型窗口/输出预留由用户按端点、协议和模型核实配置，未知窗口不显示比例，预留不修改真实模型输出参数。输入或范围变动后需重算。`/compress`或按钮在停止运行后以本地摘要保留最近至多2个完整轮次，不请求模型、不改变原始Run与证据，可能损失旧细节。单轮或压缩结果超限应增加预算、减少读取或新建会话，不截断工具配对。

输入`/`搜索命令，方向键选择、Tab/Enter填入，再发送执行；支持`/compress`与`/compact`别名、`/new`、`/help`、`/stop`、`/context`、`/sessions`、`/models`。未知命令与多余参数在本地报错，没有Provider也可操作；普通斜杠文本用`//`开头。中文输入法候选确认不会发送。

## Agent调试与外层设备状态

切换调试模式后可让Agent管理开始/暂停/继续/停止抓包、Mac系统代理，准备手机接入并打开指导，读取四层连接证据，按你批准的IP授予一次/记住/拒绝。Mac不能代替手机修改Wi-Fi代理或安装/信任CA，工具不会自动授权陌生地址或开启全域解密。主窗口顶栏下方展开手机代理状态，查看待授权地址、最近活动与许可，也可直接允许/撤销；直达、HTTP和HTTPS证据按来源及当前配对时效单独展示。配对过期、撤销或读取失败不继续显示验证通过；5秒单飞刷新，后台暂停。IP非设备身份，也不是持续在线证明。

QA→编辑重放支持新建空白Compose或载入已选抓包，编辑URL/方法/重复Header/文本或Base64正文，选择直连或本地代理。高级重复支持次数1–20、并发1–3、全局派发间隔0–10000ms、整组总时限5–60秒；单次等待最多30秒。单条请求/响应正文5MiB、整组请求正文20MiB。先生成整组固定预览，确认后发送；配置、来源版本、监听、CA或弱网改变需重建预览。代理HTTPS须已显式开启目标Host解密，只额外信任本项目CA；直连不应用代理规则或弱网，不跟随重定向。HTTP错误/失败/截断/未知停止后续派发，并发已发请求不能撤销。任务可停止、核对状态、按每页20组摘要浏览完整历史；中断不自动恢复，已执行预览不重复发送。代理模式由实际代理产生唯一抓包行，capturePending表示保存尚未确认，状态会只读核对实际唯一记录并区分已保存/失败/未知，30秒未确认转未知；可手动重查。Agent保留1–10次便捷入口并增加空白Compose、高级重复和状态工具，整组发送始终审批。Shell逐条展示命令并人工批准，20秒/64KiB，`zsh -f`、当前项目工作目录，无Provider凭据环境继承；同账户权限且非沙箱，可能读写文件或联网。新代理/手机/许可/Shell/批量发送不会因自动执行开关而跳过批准。

设置→供应商→编辑→「已保存账户与密钥详情」可主动显示或隐藏已存Key；30秒、切出窗口、关闭或切账户会清空显示。新输入也可切显隐；查看不会把旧Key填入编辑值，不会误保存/清空。分析记录/报告默认折叠、标题缩小；展开显示原问题摘要、中文状态与时间，Run每页12条、报告每页8条，可继续翻页访问旧记录。完整逐项说明见[RF01–RF56](problem-fixes-status.md)。


大体积单轮历史也可使用`/compress`；缩减是本地固定节选，不请求模型、不重放工具。原Run和证据保留，但模型历史会省略工具正文和部分旧文字。原问题较长时摘要仅为线索，需回原Run核对；当前Run内的工具增长仍不承诺无限上下文。
