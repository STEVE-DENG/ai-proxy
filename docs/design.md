# 界面与图形约定

保留现有抓包工作台的森林绿与纸色语言；内容左对齐、请求紧凑成行，给正文和对话更多空间。不要为了统一尺寸把字段值、错误或按钮裁掉。状态文字必须和图形一起表达含义。

| 角色 | 浅色 | 深色 |
| --- | --- | --- |
| 页面 | `#eee9dd` | `#141c19` |
| 控件表面 | `#faf7ef` | `#202c26` |
| 正文 | `#17231e` | `#f0f1e8` |
| 次要文字 | `#59594e` | `#b0bcaf` |
| 主操作/证据 | `#315e4a` | `#9bd2ae` |
| 警告/错误 | `#b47c24` / `#a93f39` | `#e4ba73` / `#f09891` |

Manrope用于界面，Newsreader只用于标题，等宽字体用于协议字段。遵循用户100–200%文字大小；列表行高随字号/密度变化，菜单和启动页允许滚动。深色模式同时覆盖表面、文字、边界、成功/警告状态与输入控件，不使用整页反相。

所有选择控件共用`Select.tsx`。原生select保留值和真实change事件，触发按钮维持键盘焦点；浮层使用listbox/option语义、aria-activedescendant、已选择标记、禁用态与前缀定位。滚动/窗口失焦/控件隐藏时收起，Esc先收菜单再收弹窗。菜单尺寸受视口限制。

按首次使用加载QA工作台，已访问内容保持挂载；不要用关闭弹窗来丢弃预览和不确定结果。小窗时允许顶部工具栏横向滚动，保持输入区、停止与恢复入口可达。当前未实际执行深色/高字号/键盘的桌面验收，待办继续保留。

[生成图资源与完整提示词](media/README.md)记录新图标和README概念图。图标透明外角适配浅/深桌面，不以生成插图冒充产品截图。架构图按源码的数据和权限边界绘制。
