# 功能与支持边界

[返回 README](../README.md) · [实施状态与路线图](roadmap.md) · [人工验收](validation.md)

这里描述当前代码的能力和限制；真实环境验收状态见单独清单。

## 核心能力

### 抓包与检索

- 支持本机与手机 HTTP(S) 抓包、按域名解密、Map Local、Map Remote、Rewrite、弱网和 CONNECT 记录。
- 按 Host、目录、方法和路径组织按需加载的抓包树，合并单子节点目录，默认折叠重复请求实例，同时保留每次独立请求。
- 抓包列表采用虚拟化渲染，支持结构/时序视图、全部收起、逐层展开、键盘上下移动和筛选条件统一。
- 支持按设备、环境、时间、接口、HTTP 状态、业务状态和 Trace ID 检索；服务端分页返回匹配总数、已加载数和批次总量。
- Header、URL/Query 和正文按需读取；JSON 支持 JSON Pointer，正文支持分段继续读取，并区分缺失、采集截断、流式未保存、CONNECT 和解码失败。
- 支持接口/状态/业务状态/设备聚合、失败率、P50/P95/最大值、字段 Diff、动态字段忽略和成功/失败场景配对。

### AI Agent

- 每轮 Run 固定批次、筛选、设备、时间范围与请求版本，工具在应用侧再次校验 Scope，不能读取范围外请求。
- Agent 使用 PydanticAI 执行 ReAct 工具循环，可检索分页、读取字段、聚合、对比、查询 Trace、判断业务状态和生成人工验证清单。
- 工具参数、结果、耗时、错误、成功/失败/拒绝/超时/取消状态持久化；模型消息和 Run 事件也写入 SQLite。
- 支持流式进度、完整轮次历史压缩、重启后查看、中断后继续、前端重连补读事件和中断证据保留。
- Run 可限制步骤、工具次数、单次工具耗时、模型请求耗时、审批等待、总时限和 Token；预算耗尽会显示未检查范围。
- 默认只读。只有调试模式注册写工具，写操作必须预览并审批；停止 Run 会清理待审批操作。
- 分析回答区分已知事实、候选原因、待验证项和证据/限制；证据卡片可跳回原请求，并定位、高亮 Header、Query 或 JSON 正文字段。

### QA 工作流

- 创建、命名和结束 QA 场景，人工加入或排除请求，配置业务成功码、错误字段和关联字段。
- 展示跳转、重试、时间邻近候选、人工归组和有效 W3C Trace 分组，明确区分代理可见关联与推断关系。
- 配置环境、App 版本和构建信息，保存业务规则与常用筛选。
- 调试变更提供 before/after 预览、影响范围、配置版本和幂等键；应用后可恢复，配置冲突时拒绝覆盖。
- 保存规则、弱网和调试操作版本，保留规则命中与 Header 修改前后证据；可通过新增请求验证变更效果。
- 生成可编辑缺陷报告，记录环境/App/构建、固定范围、复现事实、预期/实际、数据缺口、调试动作和人工清单，导出 Markdown/JSON。
- QA 工作台提供编辑重放、变量步骤复现、成功基线回归、故障矩阵、鉴权诊断、文件与流、人工验证、证据交接和操作历史。
- 重放固定预览中的 URL/方法/重复 Header/正文，人工确认后只发送一次；响应作为新抓包关联原请求。步骤支持变量提取和预期状态，每步执行后暂停，前置失败停止。
- 空列表、缺字段、业务错误、401/429/500、延迟和中断使用本地 Mock 模板；人工执行业务后保存验证结果，可以恢复整个矩阵组。
- 跨场景和基线回归使用唯一接口/业务步骤/业务键配对，重复键与未覆盖样本单列，不按位置强配。
- 顶栏选择独立项目，隔离数据库、正文、规则、环境、场景和会话；切换前停止采集并收束 Agent/后台任务。
- 报告可生成有大小/样本限制的脱敏证据包，带完整性摘要和来源失效标记；导入只读，不执行包含的动作。人工清单可编辑、记录结果并持久化。

### 集成

- 导入和导出 HAR；导入创建独立批次。原始 HAR 导出保留敏感原文并先确认，上限2万条/20MiB，附未包含数；对外交接可使用脱敏证据包。
- 导入 OpenAPI/Swagger，校验状态码、必填字段和类型，并按路径模板聚合当前抓包接口。
- 导入 OTLP JSON Span，关联代理请求与服务端 Span，展示跨服务瀑布、异步候选项、采样、时钟偏差和链路缺口。
- 当前按用户要求暂不新增外部平台接入。原通用 Trace GET、有限 HTTP MCP tools/call 和 Webhook 骨架保留；不视为标准 MCP 客户端或已验收的平台适配。
- 重放/工单/调试动作历史持久化；目的地、版本与预览绑定，未知结果须人工核对，不自动重发。

### 隐私与数据

- 统一确定性脱敏覆盖 Header、URL/Query、JSON/表单正文、Diff、工具结果、Trace/MCP 查询和报告导出；稳定脱敏值用于字段比较。
- SQLite schema 5 逐版本迁移；升级前备份，失败恢复，未来版本拒绝降级。清批次可保留报告并标记来源失效；清分析数据与清项目分别说明范围，保留供应商账户与 Keychain。
- Scope 绑定签名、请求版本与配置 Hash。来源变化后明确拒读旧版本并提示创建新范围；本应用不保留无限历史正文。
- 草稿按会话/项目保存；本地原始正文与模型脱敏分段视图分别呈现。分享证据包前提供预览。
- 采集背压丢失、规则错误、TLS 错误、请求进行中和正文状态都会显式展示。

## 已知边界


- 重点支持 HTTP/1.1 和 HTTP/2。可选择保存 SSE 事件和 WebSocket 消息，每条流最多500条/256KiB；提供时序、结束/关闭状态和限额，不提供帧编辑，分片由协议层合并。历史未保存的流无法补全。
- 不支持 HTTP/3/QUIC、原始 TCP/UDP、gRPC 解码。
- Android 7+ 的正式 App 可能不信任用户 CA；证书固定的 App 无法仅靠代理获取明文。
- 设备未信任 CA 时不能解密 HTTPS；请先在证书页完成安装和完全信任。
- 流式或超过 5 MiB 的正文只保留有限记录，不会执行整段正文替换。
- 脱敏是本地尽力规则，覆盖常见敏感键名和模式，不替代专用 DLP；非结构化业务自由文本仍可能含隐私数据。
- 树使用 SQL 聚合、每层节点分页和可见节点虚拟化，实例/时序使用虚拟列表；保存节点页码和列表滚动窗口。聚合最多10万请求，关系最多1万请求/1万返回边，超限显示 coverage。只读后台作业支持取消。
- OpenAPI/Swagger 是声明支持的 JSON 校验子集；不支持的引用/关键词、深度/数组预算等返回 partial，未检查不计通过。
- 请求开始时冻结规则和环境；带宽预算跟随 runtime 变化，捕获记录明确此边界。
- OTLP 当前导入 JSON，不直接接收 protobuf；代理请求与 Span 的关联可能是启发式候选，不证明服务端根因。
- 重放直连，不应用本代理规则/弱网，不自动跟随重定向或重试；正文最多保存5MiB，网络未知结果不能证明服务端未执行。
