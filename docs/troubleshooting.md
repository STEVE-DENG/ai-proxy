# 故障排查

[返回 README](../README.md) · [使用指南](user-guide.md) · [开发指南](development.md)

## 引擎无法启动或打包缺少 sidecar

全新 checkout 先执行 `npm ci`、`npm run engine:sync` 和 `npm run engine:freeze`。冻结文件名必须匹配当前 Rust host tuple；复制另一架构的 sidecar 不能替代本机构建。

开发模式检查 `engine/.venv/bin/python` 与 Python 3.12。打包模式必须包含 `AI Proxy.app/Contents/MacOS/ai-proxy-engine`，不会使用源码回退。查看 stderr 中第一条引擎错误，不上传原始抓包和凭据。若旧数据库版本高于支持版本，使用匹配的新代码；不要手工降低 schema 版本。

## unable to open database file / persist-failed / 一直进行中

本次修复关闭了每次使用后的 SQLite 连接，并移除了错误回调中不存在的字段。旧版本在持续流量中可能耗尽文件句柄，并在连接失败时遗漏终态。安装新版本后需要完全退出旧进程，再重新打开；重开会将遗留的进行中记录标为中断，不会补造丢失的响应。

`persist-failed` 表示写入失败次数，不等于丢失了相同数量的独立请求。若新版本仍报错，检查当前项目数据目录是否仍存在、是否可写、磁盘空间是否足够，以及是否同时运行多个应用副本。不要删除数据库、正文或凭据来“修复”。

普通请求从收到请求Header起120秒未完成则超时；SSE按正文数据刷新120秒空闲期限，WebSocket按连接收发刷新空闲期限，持续有数据的长连接不受普通请求总时限限制。强制结束超时请求会关闭承载连接，同一HTTP/2连接上的其他流也可能中断。纯CONNECT隧道使用内核TCP空闲超时，无法展示未解密的内部HTTP请求。

请求查询/详情在引擎20秒内未完成会返回可重试的读取超时，取消SQL扫描；桌面和界面也设有限时等待。写操作的回执超时不代表操作未执行，应先核对结果。

## 端口被占用，或开始抓包后没有流量

默认端口是8080。停止代理后在设置修改端口，手机和系统代理同步使用新端口。确认系统/设备流量确实经过该代理；一些应用使用自己的代理设置、QUIC 或连接复用，不保证受系统 HTTP 代理控制。

空树还可能是项目、批次、设备或时间筛选不匹配。先核对匹配数/已加载数/批次总数，再放宽筛选。查询错误应有重试入口，不能把错误当作没有请求。

## HTTPS 只有 CONNECT 或 TLS 错误

依次检查：当前项目是否启用该 Host 的解密 → 设备是否安装当前项目 CA → 是否完全信任 → 新连接是否已建立。iOS 安装描述文件后还需开启完全信任；Mac 在钥匙串中核对信任。Android 用户 CA 限制和证书固定可能阻止解密，本项目不自动绕过。

CONNECT 是连接记录，不能据此断言业务响应为空或请求成功。解密设置仅影响新连接。

## Mac 在退出/崩溃后无法联网

先查看应用的本机系统代理状态，尝试正常恢复。若应用已无法打开，在 macOS「系统设置 → 网络 → 当前网络服务 → 详细信息 → 代理」核对 HTTP/HTTPS 代理。恢复到使用本工具前的配置；公司/VPN 原本要求的代理不要盲目删除。

手机还要单独关闭当前 Wi-Fi 的手动 HTTP 代理。网络服务、IP 或 Wi-Fi 变更后，原先保存的代理恢复信息可能不对应当前服务。不要通过删除数据库解决网络设置问题。

## 正文只显示一部分或无法读取字段

区分以下状态：预览截断可继续读取本地保存内容；采集截断、missing、stream-not-saved、CONNECT 或解码失败无法通过“加载更多”补回。普通正文最多保存5 MiB，SSE/WebSocket 保存另有限额。历史未启用流记录的内容不能补全。

JSON Pointer 只适用于完整可解析的 JSON；字段不存在与被采集截断而不可判断是不同结果。重复 Header/Query 不能用简单字典读取替代。

## 证据过期、范围变化或未定位到字段

Run 固定来源版本。请求完成、修改业务规则、切换环境、清理批次后，旧证据可能失效；这不是自动扩展调查范围的理由。保留旧报告说明，在当前数据上建立新 Scope/Run。

跨层/跨页证据定位已有代码，但真实深目录 UI 仍待验收。报告问题时提供合成样本分布、目标页位置和实际 locator，不只提供“跳转失败”。

## Provider 报错、超时或预算耗尽

核对协议、模型名、Base URL、设置中的本地凭据状态和 Key 和端点是否支持工具/流式响应；供应商连接成功不等于完整工具循环可用。看具体 Run 与工具状态区分模型失败、工具错误、拒绝、取消和预算限制。

出现网络未知结果时不要重复执行写操作。先查操作历史和服务端实际结果；只读调查可以在明确当前 Scope 后继续。真实 Provider 的工具循环与这些异常路径仍需按 A11 人工验收。

## 重放、恢复或契约显示 conflict / partial

重放和调试预览绑定请求、配置、所有者和文件版本；变化后重新预览，而不是绕过检查。恢复冲突表示当前配置与动作预期不一致，先人工核对现配置。

OpenAPI `partial` 表示不支持的引用/关键词、截断或预算限制；不等于通过整个规范。HAR 和证据包的样本/大小上限也会导致部分导出，请查看未包含数。

## 报告问题时提供什么

使用 [Bug 模板](https://github.com/STEVE-DENG/ai-proxy/issues/new?template=bug_report.yml)，附版本/commit、macOS/架构、入口、复现步骤、实际错误和最小合成样本。若涉及模型，提供协议/模型和工具状态；若涉及性能，提供样本量/分布、耗时、峰值内存和丢失数。脱敏并人工复核后再公开资料。


## 升级后提示尚未保存本地凭据

本版本不访问Keychain。旧用户在设置中重新录入一次Key；已存文件用户无须重复录入。检查凭据状态，读取失败时核对文件权限/磁盘空间；损坏的 `auth.json` 不会被静默覆盖。不要把文件内容发到Issue。401/403表示供应商鉴权结果，与本地是否成功读文件分开处理。CA信任仍可需要系统授权。

## 手机看到403、二维码过期或绿勾消失

首次请求需在Mac允许来源地址，允许后刷新手机页面。先关闭手机代理扫码验证直达，再配置代理验证HTTP；安装并信任CA、开启解密后验证HTTPS。配对10分钟过期，轮询约2分钟停止；切网/睡眠间隔/停止后重新配对。地址许可按IP匹配，撤销不再使用的地址。只开启LAN不设置Mac系统代理也可抓手机。

## 缓存低、文字太小或底部操作看不到

缓存用量先区分供应商与本地工具缓存；未知不等于0%命中。兼容端点拒绝缓存参数时选择关闭，避免重复收费重试；更换模型/Scope、上下文压缩和工具变化都会影响复用。真实命中率仍需同模型多轮人工比较。

帮助页可调整文字与密度、重置显示；窄窗收起会话栏或展开详情。长弹窗/工具栏本身可滚动。仍不可达时报告窗口尺寸、文字比例、所在页和最小合成样本；不要以缩小到不可读作为解决办法。错误常驻可关闭，复制诊断摘要只带版本/时间/区域/Run ID和状态，不含错误原文或抓包，复现步骤需另行提供。


## 存储健康检查未通过

在设置的存储页主动检查，按磁盘余量、项目/正文目录读写和数据库只读访问分别处理。目录不可写时恢复当前账户权限，磁盘不足时释放空间；不使用删除数据库作为恢复步骤。复制诊断会去除路径且不带抓包正文、请求Header或Key。时间/失败计数仅对应本次项目打开，临时检查成功不能证明旧失败请求已经找回；检查失败也不自动判定数据库损坏。

检查超时后如提示上次检查仍在等待磁盘响应，先恢复磁盘；后端不会因为前端停止等待就强行中断文件系统操作，也不会并发重复探测。

## 长请求被中断，或另一个HTTP/2请求也断开

在抓包设置调整普通请求总时限/流空闲时限，保存后对新请求生效。超时会关闭承载连接，HTTP/2多流共享连接时可能一起断开。若要减少连带影响，可停止代理后关闭HTTP/2再启动；该操作改变协议协商，不等于已实现单流取消。持续有正文数据的SSE不应按普通请求总时长结束，WebSocket心跳计入连接活动，真实链路需人工核对。

## 任务回执未知与比较结果未知

展开主窗口或弹窗底部的任务入口。读取超时可回原功能缩小范围再读；写回执未知先查看历史和目标业务，不能直接再次发送。执行记录的缓存比较只读已有Run，不会补发模型请求；旧Run缺少新增条件指纹时不判定可比，未上报Token保留未知，不显示虚假的0%或费用。
