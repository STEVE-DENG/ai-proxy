在 Mac 上查看 HTTP(S) 请求，用 AI 查找字段与证据，再复现问题、记录验证结果。

## 下载与安装

**本次提供 Apple 芯片 Mac（M 系列）的安装包。Intel 安装包尚未发布。**

1. 下载 `AI-Proxy-0.2.1-macos-arm64-preview.dmg`，打开后将 `AI Proxy.app` 拖入「应用程序」。也可使用同平台 ZIP。
2. 升级前退出旧应用并备份完整应用数据目录。已有数据与本地密钥继续复用。
3. 当前包为临时签名、未经过 Apple 公证，首次打开可能需要在「系统设置 → 隐私与安全性」核准。请先核对来源，不要关闭系统保护。
4. 首次使用可从「帮助」选择离线导入、本机抓包或连接手机。离线查看不需要模型账户；AI 分析需要配置自己的模型服务。

校验文件同时列出 DMG 和 ZIP 的 SHA-256；构建信息列出源码提交与二进制指纹。只下载一个包时，对照其对应的一行校验值。
