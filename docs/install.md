# 安装与第一次使用

[返回 README](../README.md) · [使用指南](user-guide.md) · [故障排查](troubleshooting.md)

## 下载哪个包

维护者发布后，可从 [GitHub Releases](https://github.com/STEVE-DENG/ai-proxy/releases) 下载与芯片一致的版本；本地准备的产物不代表已有公开 Release。

| Mac | 文件名中的平台 | 当前验证情况 |
| --- | --- | --- |
| Apple Silicon（M 系列） | `macos-arm64` | 本机编译与包结构检查；功能仍按待办验收 |
| Intel | `macos-x64` | 配置了独立 CI 构建；尚未执行、未在 Intel 实机验收 |

应用声明最低 macOS 11；本机系统为 macOS 15.3.1，较旧系统的安装与运行仍需验证。不提供 Windows/Linux 安装包。

下载对应 DMG 与同平台 `SHA256SUMS` 文件。需要校验下载内容时，在下载目录运行 `shasum -a 256 -c AI-Proxy-版本-平台-SHA256SUMS.txt`；清单同时列出 ZIP 和 DMG，只下载其一时对照该文件对应的一行。

## 拖入 Applications

1. 打开 DMG，将 `AI Proxy.app` 拖到 `Applications`。也可解压 ZIP 后拖入应用程序目录。
2. 从 Applications 打开。包内包含 Python 引擎，使用者无需安装 Python、Node、Rust、uv 或后台服务。
3. 当前带 `preview` 的 ad-hoc 包未经过 Apple 公证，macOS 可能要求在「系统设置 → 隐私与安全性」核准打开。只核准你核对过来源的包，不关闭系统保护。正式顺畅分发还需维护者的 Developer ID、公证和另一台干净 Mac 验证。

更新前正常退出旧应用，保留完整应用数据目录。不要在运行中替换；安装包不会替你清理设备上的旧 CA。

## 首次打开

启动页显示引擎、数据、工作区三个实际阶段和已等待时间，不显示伪造百分比。Python 引擎会在本地准备目录、数据库和 CA；不需要另开服务。首屏数据返回即可进入，代理状态/历史读取不会阻塞整个工作区。连接等待有95秒上限，失败后保留错误与主动重试入口。

在帮助页选一条路径：

- **先看看数据**：离线导入 → 体验合成示例。无需代理、手机或模型账户，可查看请求、正文与证据位置。
- **连接手机**：选择同一 Wi-Fi 的 Mac 地址 → 开启 LAN 监听 → 按手机引导设置 Wi-Fi HTTP 代理 → 允许对应来源地址 → 验证 HTTP。只抓手机时不用挂载 Mac 系统代理。
- **抓本机**：开始抓包，在设置中启用本机系统代理，或仅让目标程序手动使用本代理。
- **AI 调查**：在设置保存 Provider/模型/密钥，先选范围再输入问题。密钥保存在权限受限的本机明文文件，重启复用，无 Keychain 授权流程；旧用户首次迁移需重新填写一次。

HTTPS 默认关闭；需要解密时按 Host 开启并在设备安装、信任项目 CA。Wi-Fi 代理和证书信任属于设备系统操作，不能被 Mac 上的按钮代替。结束后关闭手机代理并核对 Mac 代理恢复。

## 外观与布局

帮助 → 外观：跟随系统、浅色、深色；文字100–200%，舒适/紧凑密度。下拉菜单支持方向键、Home/End、输入前缀、Enter确认、Esc关闭。弹窗或工具栏滚动后菜单关闭，避免悬空。

抓包默认逐条请求；可切换目录折叠，保留每次请求实例。面板分隔条可拖动或用方向键调整；Agent侧栏、历史和上下文可收起。窄窗、高字号的完整桌面验证尚未标记通过。
