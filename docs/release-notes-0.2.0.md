# AI Proxy 0.2.0 开发预览

本版本补齐界面外观和安装分发工具，并继续修复长对话与启动等待。所有原 TODO 保持开放，直到逐项满足要求并有验证依据。不是稳定版或全量功能验收通过的声明。

- 全部下拉入口使用统一菜单、键盘导航与视口内定位；新增浅色、深色、跟随系统，保留文字大小和密度设置。
- 新的森林绿网络图标，同步 Dock/应用图标、顶栏和启动页；README增加原创概念图和可追溯架构说明。
- 单个历史轮次过大时以有标记的本地节选继续，不再要求立即新开会话；完整原Run保留，未知写结果不自动重试。/compress也处理单个大轮次；不调用模型。
- 启动显示实际阶段和等待时间；可用首屏先显示，历史/代理状态失败在工作区提示。本机代理状态读取10秒超时。
- 工作台按首次使用加载，关闭后保留状态；版本信息可在帮助页查看。
- 本地生成按版本/架构命名的DMG和ZIP，附SHA-256、源码/二进制指纹及依赖声明。签名、版本和源码匹配检查失败时拒绝分发/安装。
- 本机替换保留旧包备份，运行中延后；不自动启动。GitHub手动流程分别构建arm64与Intel，默认只保存产物，可显式创建草稿预发行，永不自动公开发布。
